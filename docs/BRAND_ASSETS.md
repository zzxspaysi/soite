# Логотипы в ленте производителей

Состав и порядок ленты заданы в `components/brand-marquee.tsx`. Маленький
зелёный знак из референса исключён по просьбе владельца. ШТРИХ-М и Zebra
сохранены из прежнего блока производителей.

Файлы хранятся в `public/brands/` и загружаются с самого сайта, без обращения
к серверам производителей при просмотре страницы.

- `atol.png`: красный логотип, встроенный в
  [страницу сервисного центра прежнего сайта ANADO](https://anado.ru/asc.html).
- `shtrih-m.gif`: изображение из
  [раздела загрузок прежнего сайта ANADO](https://anado.ru/website/anado/var/custom/Image/shtrih.gif).
- `zebra.svg`: векторный логотип из
  [публичного файла Zebra](https://github.com/waqastayyab2004-tech/hitechtechnologyhub/blob/d045c345a0ba849b9fd44f703be5494430af5b09/public/zebra-logo.svg).
- `brand-logos.webp` и `paytor.webp`: прозрачные изображения, подготовленные через image generation
  по двум присланным владельцем изображениям. Это восстановление по референсу,
  а не скачанный официальный брендбук. Перед окончательным выпуском желательно
  заменить восстановленные изображения оригинальными файлами производителей,
  если они будут предоставлены. WebP сжат без потери пикселей PNG.

Атлас состоит из трёх столбцов и четырёх строк:

| Строка | Слева     | По центру                                     | Справа        |
| ------ | --------- | --------------------------------------------- | ------------- |
| 1      | SPACE     | АТОЛ (на странице используется отдельный PNG) | Эвотор        |
| 2      | iiko      | POScenter                                     | DataMobile    |
| 3      | Клеверенс | MERTECH                                       | MINDEO        |
| 4      | TSC       | PAYTOR (используется отдельный WebP)          | Пустая ячейка |

Чтобы заменить восстановленный логотип, добавьте файл в `public/brands/`
и у нужного бренда замените поле `sprite` на `src: "/brands/имя-файла.svg"`.
Разметка поддерживает оба варианта. Названия доступны экранным дикторам,
а дублирующая группа скрыта от дерева доступности.

Лента имеет две одинаковые группы, поэтому переход между кругами непрерывен.
Движение включено автоматически, в том числе при системной настройке уменьшения
движения, согласно ранее указанному предпочтению владельца сайта. Пользователь
может остановить и продолжить его кнопкой справа от заголовка.
